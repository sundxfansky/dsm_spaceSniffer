# DSM Storage Inspector

一个可通过 Docker 部署的群晖存储分析 Web 服务。它通过 SSH 执行只读命令，支持：

- 发现并选择多个 `/volumeN` 存储空间
- 查看容量、使用率和一级文件夹占用
- 按阈值列出大文件
- 按 inode 聚合硬链接及其全部路径
- 可配置多个 Transmission RPC 服务器及其到 DSM 的挂载路径映射
- 找出下载时间超过 30 天、单文件大小不超过上限、且硬链接路径包含“电视剧”的清理候选
- 对候选项一键删除 Transmission 任务、下载文件和全部硬链接，并在每个删除路径旁创建 `.rmed` 标记文件
- 在浏览器筛选结果并导出 JSON
- 完整保留匹配结果，每页显示 100 条，搜索与导出覆盖全部结果
- 边扫描边展示：文件清单通过 SSH 分块读取，约每两秒发布快照，浏览器持续更新文件、硬链接和大文件夹；错误发生后保留已发布的部分结果
- 大文件夹按每条普通文件路径的逻辑大小递归汇总，包含多层子目录；多个小文件合计达到阈值同样列出。硬链接每条路径分别计数，父子目录不能相加，不代表实际磁盘占用或可释放空间
- 扫描中目录大小是当前已读取的累计值；阶段进度并非已扫描字节百分比。一级目录的实际分配空间由后续 du 阶段统计

## 群晖准备

1. 打开 DSM 的“控制面板 -> 终端机和 SNMP -> 终端机”。
2. 启用 SSH 服务，并确认端口（默认 `22`）。
3. 使用对目标共享文件夹具有读取权限的 DSM 账户。扫描不到的目录通常是权限不足导致的。

服务接受 DSM URL（例如 `https://nas.local:5001`）或主机名/IP；URL 只用于提取主机名，实际分析连接使用表单中的 SSH 端口。

## Docker 部署

```bash
docker compose up -d --build
```

打开 <http://localhost:8080>。

停止服务：

```bash
docker compose down
```

## 本地开发

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
uvicorn app.main:app --reload --port 8080
```

测试：

```bash
pytest -q
```

## 安全与扫描说明

- “空间地图”提供类似 SpaceSniffer 的固定外框矩形树图，按已扫描逻辑大小分配面积，点击目录下钻、面包屑或“上一级”返回。地图随扫描更新，保留当前位置；停止后仍可浏览。目录和单个文件（含阈值以下文件）均可展示，阈值仅筛选大文件/大文件夹列表。扫描时在服务进程内存中建立完整文件索引，不写入群晖或数据库文件；进入目录按需读取索引，右侧每页 30 项，可搜索全部已读文件，零字节文件也在列表中显示。顶层图面展示至多 80 项，其余面积合并但不丢弃；嵌套预览有层数和节点数限制。搜索高亮图面并筛选侧栏，不改变面积比例。首次预览为每目录最多 8 个文件、最多 1000 个目录，未预览文件仍可进入目录后分页读取。旧结果需要重新扫描才有完整索引。前端无需外部 CDN，不上传文件信息。
- 全部小文件索引随任务保留在内存，扫描停止/失败后仍可查询，重启服务后失效。导出 JSON 包含原有大文件结果、目录统计及有限文件预览，并非完整小文件清单。
- Transmission 连接使用 RPC（默认 `/transmission/rpc`）。无需填写路径映射：分析开始时先读取任务列表，扫描所选存储空间时按“相对路径 + 文件大小”比对，自动找到 TR 下载根目录（每台服务器可填写，默认 `/downloads`）下每个一级目录对应的 DSM 路径（各一级目录分别定位，可来自不同共享文件夹；按匹配文件数投票决定）。只处理根目录下的任务，未找到对应路径的目录会在警告中列出并跳过。连接卡片会显示在线状态、任务数量，并在扫描过程中实时更新当前定位到的挂载目录（扫描结束前未找到的显示“查找中”）。候选默认条件是已完成且下载时间超过 30 天、单文件不超过 1024 MiB、硬链接组中至少有一条路径包含“电视剧”，可在页面调整天数和大小上限。清理操作会通过 DSM SSH 删除候选文件及所有硬链接，创建同名 `.rmed` 空文件，再调用 Transmission `torrent-remove`（不让 TR 重复删除本地数据）；任何一步失败都会逐项报告并保留警告。

- 连接信息（包括密码）自动加密保存在当前浏览器的 IndexedDB 中，刷新和重开页面后自动填回。使用 AES-GCM 和不可导出的浏览器密钥；不上传保存到服务端，不使用明文 localStorage。需要 localhost 或 HTTPS，同一浏览器配置及网站来源；清除网站数据会清除保存信息。浏览器本身仍能解密，无法防范同源恶意脚本或已被接管的浏览器。
- 服务端密码仅用于当前请求及后台任务，不写入文件或日志。旧版本没有保存的密码需要重新输入一次。
- 连接后显示远端 `id -u` / `id -un` 的实际身份。UID 0 才表示此 SSH 会话为 root；DSM 管理员、容器 root 和其他终端 sudo 会话不等价。服务不会自动提权。
- 容器使用非 root 用户、只读文件系统和 `no-new-privileges`。
- SSH 首次连接使用当前会话内的临时信任，不写入 `known_hosts`；页面会显示服务器 SHA-256 指纹，建议与群晖端核对。
- 扫描阶段所有远端命令均为只读的 `df`、`du`、`find` 和 `stat`；清理阶段仅对用户确认的候选执行带绝对路径的 `rm` 和 `.rmed` 创建。
- 文件扫描包含所选存储空间及其内部挂载目录，不跟随符号链接。文件很多时会持续较长时间并产生磁盘读取负载。
- 大文件阈值单位为 MiB，包含等于阈值的文件；设为 0 则列出全部普通文件。结果不再按 500/5000 条截断。
- 扫描错误不再被隐藏。权限不足时保留可读结果并明确标记不完整；命令失败且无结果时显示失败。不会自动提权。
- 文件元数据用 NUL 分隔，支持换行、制表符和中文文件名。GNU find 不可用时回退到只读 stat。
- 硬链接即使只找到一条路径也会显示已找到/实际链接数。该统计不等同于 Btrfs 快照、压缩或去重后的实际可释放空间。
- 单次远端命令输出超过 256 MiB 时明确报错，请减少所选存储空间后重试。
- 文件夹占用为所选存储空间的一级目录统计；`du` 对硬链接只计一次，结果不会重复计算其物理占用。
- 当前任务状态保存在内存中，重启容器后会清空。
- 扫描时可点击“停止分析”，后端取消任务并关闭当前 SSH 通道/连接，保留已读取结果供查看和导出（标为部分结果）。连接建立阶段需等待连接返回或超时，界面会显示“正在停止”。停止不会修改群晖文件或发送删除命令；清理只从已发布候选中选择并逐项确认。断开 SSH 后远端进程的退出时机由 SSH 服务和文件系统决定，阻塞的远端 I/O 不保证立即结束。停止后可重新开始扫描，不支持断点续扫。
- Web 服务本身不包含登录系统，请仅在可信局域网中使用，或在前置反向代理上配置 HTTPS 与访问认证。
